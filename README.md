# Machine Learning - Master Health Data Science (MHEDAS)

Welcome to the team collaboration repository for the Machine Learning course of the Master in Health Data Science. This repository contains the code, data analysis, and reports for all the assignments completed by our team (Team 11).

## 📂 Repository Structure

This repository is divided into three main projects, each corresponding to a core paradigm of Machine Learning applied to healthcare data:

* **[Assignment 1: Unsupervised Learning](./1_UnsupervisedLearning)**
    * **Focus:** Clustering Patient Data (K-Means, GMM, Hierarchical Clustering).
    * **Dataset:** Heart Disease UCI.
* **[Assignment 2: Supervised Learning](./2_SupervisedLearning)**
    * **Focus:** Classifying Breast Cancer (KNN, Logistic Regression, SVM, Neural Networks).
    * **Dataset:** Breast Cancer Wisconsin.
* **[Assignment 3: Time Series Analysis](./3_TimeSeries)**
    * **Focus:** Classifying Cardiac Arrhythmias (RNN, LSTM).
    * **Dataset:** MIT-BIH Arrhythmia Database.

## 🛠️ General Workflow

For each assignment, we follow a standardized pipeline:
1.  **Data Exploration & Preprocessing:** Handling missing values, scaling, and feature engineering.
2.  **Modeling:** Training and hyperparameter tuning of different algorithms.
3.  **Evaluation:** Comparing models using appropriate clinical metrics (e.g., F1-score, AUC, Macro F1).
4.  **Reporting:** Writing a final scientific report discussing the findings, trade-offs, and clinical deployment viability.
